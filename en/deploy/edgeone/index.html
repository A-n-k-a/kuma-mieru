Deploy

EdgeOne Pages

Import your fork to EdgeOne Pages and deploy Kuma Mieru.

Fork the repository

Open the fork page of this repository and click Create fork.

Import the repository

Log in to EdgeOne Pages, select the option to import a Git repository, and select your fork.

Configure the build

  1. Set the root directory to apps/web.
  2. Select the Next.js framework preset.

apps/web/edgeone.json sets the install command bun install --frozen-lockfile and the build command bun run build.

Add environment variables and deploy

Add the UPTIME_KUMA_URLS environment variable with the full URL of the status page. Separate multiple URLs with |. Then start the deployment. For the other variables, see Environment Variables.

Change environment variables

The configuration is generated during the build. After you change an environment variable on EdgeOne Pages, redeploy to apply it.
